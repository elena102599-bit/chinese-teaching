# Mandarin Loop website redesign

Responsive static HTML/CSS/JS website based on your original single-page HTML.

## Pages
Home, Courses, Resources, Shop, About, Contact, Privacy, Terms and Refunds.

## Preview
Open `index.html` in a browser. No build command or framework is required.

## Before publishing
1. Replace `YOUR_EMAIL_HERE` in `contact.html` with the public contact email you want to use.
2. The shop is currently a product catalogue only. Add real product files, prices and checkout links before taking orders.
3. The contact form opens the visitor's email application; it does not store submissions.
4. Review the legal policy starter pages before publishing.
5. Upload the folder contents to your existing GitHub repository and preserve your Cloudflare Pages settings. For a plain static site, the output directory is the repository root and no build command is needed.


## Private lessons and Payhip links
- The Courses page now includes a dedicated private 1-to-1 lesson section.
- The Shop page has Payhip call-to-action buttons for the digital products and a separate 1-to-1 lessons callout.
- Temporary buttons currently point to https://payhip.com/. Before publishing, replace each button URL with the matching Payhip product page URL.
- For private lessons, create a Payhip **Coaching Service** product (rather than a regular digital download). Consider using an intake form to collect the learner’s level, goals, time zone and preferred schedule. Add the Payhip coaching product URL to both private-lesson buttons.
- For ebooks, workbooks and downloadable packs, create the corresponding Payhip digital products and replace each Shop button URL with that product's Payhip page URL.
